# 📋 Changelog - Quartz Launcher (Offline Edition)

## [1.0.0] - 2026-07-09

### 🎉 Первый релиз - Quartz Launcher

Создана версия PrismLauncher без требования авторизации в Microsoft аккаунт, переименованная в **Quartz Launcher**.

---

## 🔥 Критические изменения (Breaking Changes)

### ❌ Удалено:
- Microsoft аккаунты (MSA)
- OAuth2 авторизация
- Xbox Live интеграция
- Проверка лицензии Minecraft
- Управление скинами через Microsoft
- Обновление токенов авторизации
- Диалоги входа в аккаунт

### ✅ Добавлено:
- Автоматическое создание офлайн-аккаунтов
- Запуск без проверок авторизации
- Полностью автономный режим работы

---

## 📝 Детальный список изменений

### 🔧 Изменения в коде (6 файлов)

#### 1. `launcher/LaunchController.cpp`

**Удалено:**
```cpp
- Проверка наличия валидного Microsoft аккаунта
- Диалог выбора аккаунта (ProfileSelectDialog)
- Окно повторной авторизации (MSALoginDialog) 
- Проверка состояния токена (expired/errored/disabled)
- Обновление токенов через refresh()
- Диалог настройки профиля (ProfileSetupDialog)
```

**Изменено:**
```cpp
+ decideAccount() - Автоматически создает офлайн-аккаунт
+ decideLaunchMode() - Всегда возвращает офлайн-режим
+ login() - Упрощенная логика без диалогов
+ reauthenticateAccount() - Заглушка (всегда возвращает false)
```

**Результат:**
- ✅ Игра запускается без выбора аккаунта
- ✅ Не показываются диалоги авторизации
- ✅ Автоматически создается офлайн-аккаунт "Player"

---

#### 2. `launcher/Application.cpp`

**Удалено:**
```cpp
- #include "ui/setupwizard/LoginWizardPage.h"
- Создание страницы входа в мастере установки
- Проверка m_accounts->anyAccountIsValid()
```

**Изменено:**
```cpp
+ createSetupWizard() - Не добавляет LoginWizardPage
+ wizardRequired - Не зависит от переменной login
```

**Результат:**
- ✅ При первом запуске не показывается окно входа
- ✅ Мастер установки показывает только Language/Java/Theme

---

#### 3. `launcher/minecraft/auth/AuthSession.cpp`

**Добавлено:**
```cpp
+ MakeOffline() теперь устанавливает user_type = "offline"
+ MakeOffline() теперь устанавливает launchMode = LaunchMode::Offline
```

**Результат:**
- ✅ Офлайн-сессии корректно идентифицируются игрой
- ✅ Игра знает, что запущена в офлайн-режиме

---

#### 4. `launcher/ui/pages/instance/VersionPage.cpp`

**Удалено:**
```cpp
- Проверка anyAccountIsValid() при скачивании
- Диалог с ошибкой "Cannot download Minecraft..."
```

**Результат:**
- ✅ Minecraft можно скачивать без создания аккаунта
- ✅ Не требуется Microsoft аккаунт для обновления инстансов

---

#### 5. `launcher/minecraft/auth/AccountList.cpp`

**Изменено:**
```cpp
- anyAccountIsValid() - Раньше: проверял ownsMinecraft()
+ anyAccountIsValid() - Теперь: возвращает true если есть любой аккаунт
```

**Результат:**
- ✅ Офлайн-аккаунты считаются валидными
- ✅ Все проверки в коде работают с офлайн-аккаунтами

## 🎯 Новое поведение

### При первом запуске:
```
Раньше: Показывался мастер → Страница входа Microsoft → Диалог авторизации
Теперь: Показывается мастер → Только Language/Java/Theme → Готово!
```

### При запуске игры:
```
Раньше: Проверка аккаунта → Выбор аккаунта → Обновление токена → Запуск
Теперь: Автосоздание офлайн-аккаунта → Запуск
```

### При скачивании Minecraft:
```
Раньше: Проверка наличия Microsoft аккаунта → Скачивание
Теперь: Скачивание сразу
```

## 🐛 Исправленные баги

### Issue #1: Требование Microsoft аккаунта
- **Раньше:** Нельзя запустить игру без Microsoft аккаунта
- **Теперь:** Игра запускается автоматически с офлайн-аккаунтом

### Issue #2: Диалоги авторизации при каждом запуске
- **Раньше:** При истечении токена показывались диалоги
- **Теперь:** Никаких диалогов, только офлайн-режим

### Issue #3: Невозможность скачать Minecraft без аккаунта
- **Раньше:** Требовалось добавить аккаунт перед скачиванием
- **Теперь:** Скачивание работает без аккаунта
