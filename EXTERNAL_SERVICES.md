# Внешние сервисы PrismLauncher - Краткая сводка

## 🔴 Критичные (обязательны для работы)

| Сервис | URL | Назначение | Можно заменить локально? |
|--------|-----|------------|-------------------------|
| Minecraft Libraries | `libraries.minecraft.net` | Библиотеки Java для игры | ✅ Да |
| Minecraft Resources | `resources.download.minecraft.net` | Текстуры, звуки, шрифты | ✅ Да |
| Meta Index | Настраивается в BuildConfig | Версии Minecraft и модлоадеров | ✅ Да |

## Режимы работы

### 🌐 Полный онлайн режим (стандартный)
- Все сервисы доступны
- Microsoft аккаунты работают
- Автоматические обновления
- Загрузка модов

### ⚡ Гибридный режим (ваша версия)
- ✅ Загрузка игры и библиотек
- ✅ Офлайн аккаунты
- ✅ Платформы модов
- ❌ Microsoft аккаунты отключены
- ❌ Управление скинами недоступно

### 📴 Полный офлайн режим (после настройки локального зеркала)
- ✅ Запуск ранее загруженных версий
- ✅ Офлайн аккаунты
- ✅ Локальные моды
- ❌ Новые версии игры
- ❌ Загрузка модов с платформ
- ❌ Обновления лаунчера

## Минимальные требования для работы

### Первый запуск (требуется интернет):
```
1. Подключение к интернету
2. Доступ к libraries.minecraft.net
3. Доступ к resources.download.minecraft.net
4. Доступ к мета-серверу
```

### Последующие запуски (офлайн):
```
1. Офлайн аккаунт создан
2. Версия Minecraft уже загружена
3. Запуск через "Launch Offline"
```

## Настройки для минимизации онлайн зависимостей

В Settings → API:
- ☑ Отключить `Refresh on launch` для метаданных
- ☑ Отключить проверку обновлений
- ☑ Включить `ModMetadataDisabled`

## Как перейти на полностью автономную работу

1. **Загрузите всё нужное с интернетом:**
   - Версии Minecraft
   - Библиотеки
   - Ресурсы
   - Моды (если нужны)

2. **Настройте локальное зеркало:**
   - HTTP сервер (nginx)
   - Скопируйте файлы
   - См. `OFFLINE_MIRROR_SETUP.md`

3. **Измените BuildConfig и перекомпилируйте:**
   ```cpp
   QString LIBRARY_BASE = "http://localhost:8080/libraries/";
   QString DEFAULT_RESOURCE_BASE = "http://localhost:8080/resources/";
   ```

4. **Отключите ненужные функции:**
   - Отключите проверку обновлений
   - Отключите загрузку новостей
   - Отключите метаданные модов

## Потенциальные проблемы

| Проблема | Причина | Решение |
|----------|---------|---------|
| Не запускается новая версия | Нет интернета для загрузки | Загрузите с интернетом или настройте зеркало |
| Ошибка при загрузке библиотек | Недоступен libraries.minecraft.net | Используйте локальное зеркало |
| Не работают моды с платформ | Нет доступа к API | Загружайте моды вручную |
| Медленная загрузка | Медленный интернет | Используйте локальный кэш |

## Рекомендации

### Для домашнего использования:
- ✅ Оставьте доступ к libraries.minecraft.net
- ✅ Используйте офлайн аккаунты
- ✅ Загружайте моды вручную при необходимости

### Для корпоративной/образовательной сети:
- ✅ Настройте полное локальное зеркало
- ✅ Заблокируйте внешний доступ файерволом
- ✅ Синхронизируйте зеркало периодически

### Для полностью изолированной среды:
- ✅ Локальное зеркало обязательно
- ✅ Перекомпилируйте с изменёнными URL
- ✅ Создайте автономный дистрибутив
