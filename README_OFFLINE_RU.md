## 🌟 Особенности

✅ **Без авторизации Microsoft** - не требуется аккаунт для запуска  
✅ **Полностью автономный** - работает без интернета  
✅ **Автоматические офлайн-аккаунты** - создаются автоматически  
✅ **Без диалогов входа** - никаких окон авторизации  
✅ **Поддержка модов** - Forge, Fabric, Quilt и другие  
✅ **Модпаки** - CurseForge, Modrinth, FTB и другие  

## 🚫 Что удалено

❌ Вход в Microsoft аккаунт  
❌ OAuth авторизация  
❌ Проверка лицензии  
❌ Управление скинами через Microsoft  
❌ Окна выбора аккаунта

## 🎮 Использование

### Первый запуск:

1. Запустите Quartz Launcher
2. Выберите язык (Русский доступен)
3. Настройте Java (автоопределение)
4. **Готово!** Никакого входа в аккаунт не требуется

### Добавление инстанса:

1. Нажмите "Add Instance"
2. Выберите версию Minecraft
3. Нажмите "OK"
4. Нажмите "Launch" - игра запустится!

### Создание аккаунтов:

1. Settings → Accounts
2. Нажмите "Add Offline"
3. Введите никнейм
4. Готово!

Можно создать несколько офлайн-аккаунтов с разными никами.

## ❓ FAQ

**Q: Можно ли играть на лицензионных серверах?**  
A: Нет, для этого требуется Microsoft аккаунт.

**Q: Работают ли моды?**  
A: Да! Все моды и модпаки работают нормально.

**Q: Можно ли сменить скин?**  
A: Нет, управление скинами через Microsoft отключено. Но можно использовать сторонние скин-системы на пиратских серверах.

**Q: Нужен ли интернет?**  
A: Интернет нужен только для скачивания Minecraft и модов. Запуск игры работает полностью офлайн.

**Q: Можно ли вернуть Microsoft авторизацию?**  
A: Да, используйте оригинальный PrismLauncher или откатите изменения через git.

**Q: Это безопасно?**  
A: Да! Мы только удалили код авторизации, не добавляя ничего вредоносного. Исходный код открыт для проверки.
