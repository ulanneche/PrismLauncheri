## 🔨 Компиляция

### Подготовка

- [ ] CMake установлен (версия 3.15+)
- [ ] Qt 6.x установлен
- [ ] Компилятор C++20 доступен
- [ ] Git установлен

### Процесс компиляции

```bash
# Windows (CMD)
[ ] cd C:\Users\q\Desktop\PrismLauncheri
[ ] if exist build rmdir /s /q build
[ ] mkdir build
[ ] cd build
[ ] cmake .. -DCMAKE_BUILD_TYPE=Release
[ ] cmake --build . --config Release -j4

# Linux/macOS
[ ] cd ~/PrismLauncheri
[ ] rm -rf build
[ ] mkdir build && cd build
[ ] cmake .. -DCMAKE_BUILD_TYPE=Release
[ ] cmake --build . --config Release -j$(nproc)
```

### Проверка компиляции

- [ ] Компиляция завершилась без ошибок
- [ ] Исполняемый файл создан
  - Windows: `build/launcher/Release/prismlauncher.exe`
  - Linux: `build/launcher/prismlauncher`
  - macOS: `build/launcher/PrismLauncher.app`
- [ ] Размер файла адекватный (~50-100 МБ)
