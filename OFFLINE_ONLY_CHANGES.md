# Полное удаление системы авторизации Microsoft из PrismLauncher

## Обзор изменений

Все компоненты, связанные с авторизацией Microsoft, были удалены или отключены. Лаунчер теперь работает **только в офлайн-режиме** без каких-либо требований к авторизации.

## Основные изменения:

### 1. LaunchController.cpp - Удалена вся логика авторизации

**Изменения:**
- ✅ `decideAccount()` - Упрощена: автоматически создает офлайн-аккаунт если нет ни одного аккаунта
- ✅ `decideLaunchMode()` - Всегда возвращает офлайн-режим, без проверок авторизации
- ✅ `login()` - Упрощена: создает офлайн-сессию без диалогов выбора аккаунта
- ✅ `reauthenticateAccount()` - Отключена полностью
- ✅ Удалены импорты: `MSALoginDialog.h`, `ProfileSelectDialog.h`, `ProfileSetupDialog.h`

**Удалены диалоги:**
- ❌ Окно выбора аккаунта
- ❌ Окно авторизации Microsoft
- ❌ Диалоги повторной авторизации
- ❌ Сообщения об ошибках авторизации

### 2. Application.cpp - Отключен мастер первоначальной настройки

**Изменения:**
- ✅ Переменная `login` теперь всегда `false`
- ✅ Страница LoginWizardPage больше не добавляется в мастер установки
- ✅ Удален импорт `LoginWizardPage.h`

**Результат:**
- При первом запуске не показывается окно входа в Microsoft аккаунт
- Автоматически создается офлайн-аккаунт при необходимости

### 3. AuthSession.cpp - Улучшен метод MakeOffline

**Изменения:**
- ✅ Добавлена установка `user_type = "offline"`
- ✅ Добавлена установка `launchMode = LaunchMode::Offline`

**Результат:**
- Офлайн-сессии теперь корректно идентифицируются игрой

### 4. VersionPage.cpp - Удалена проверка аккаунта при скачивании

**Изменения:**
- ✅ Убрано требование наличия аккаунта для скачивания Minecraft
- ✅ Удален диалог с ошибкой о необходимости добавить аккаунт

**Результат:**
- Minecraft можно скачивать без создания аккаунтов

### 5. AccountList.cpp - Изменена логика проверки валидности аккаунтов

**Изменения:**
- ✅ `anyAccountIsValid()` теперь возвращает `true` если есть хотя бы один аккаунт любого типа
- ✅ Офлайн-аккаунты теперь считаются валидными

**Результат:**
- Все проверки в коде, использующие `anyAccountIsValid()`, теперь работают с офлайн-аккаунтами

## Поведение лаунчера после изменений:

### При первом запуске:
1. ✅ Не показывается окно входа в Microsoft аккаунт
2. ✅ Автоматически создается офлайн-аккаунт с именем "Player" (или последним использованным именем)
3. ✅ Мастер настройки показывает только языковые, Java и тематические настройки

### При запуске игры:
1. ✅ Не требуется выбор аккаунта
2. ✅ Не проверяется онлайн-статус
3. ✅ Автоматически используется офлайн-режим
4. ✅ Если нет аккаунта, создается новый офлайн-аккаунт автоматически

### При скачивании Minecraft:
1. ✅ Не требуется наличие аккаунта Microsoft
2. ✅ Скачивание работает в любом случае

### Управление аккаунтами:
1. ✅ Доступно только добавление офлайн-аккаунтов
2. ✅ Кнопки "Add Microsoft", "Refresh", "Manage Skins" отключены
3. ✅ Можно создавать несколько офлайн-аккаунтов с разными именами

## Компиляция:

```bash
cd build
cmake ..
cmake --build . --config Release
```
